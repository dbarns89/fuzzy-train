VCX Diag: from parts to a working scan

The 12 steps to get the iPhone app reading codes from a GM vehicle through your VCX Nano. Do the blue steps once on the garage PC, the purple steps once on a Mac, and the orange steps each time you scan a car.

Set up the bridge PC

About 20 minutes

1

Install VX Manager and the GM driver

The same install Tech2Win uses. Confirm the VCX Nano shows as connected in VX Manager.

2

Install 32-bit Python 3.9+

The VCX J2534 driver is 32-bit, so the 64-bit Python can't load it.

3

Check the driver is found

Run python vcx_bridge.py --list. You should see a VX / VCX entry.

4

Start the bridge and note the address

Run python vcx_bridge.py. Allow it through Windows Firewall on private networks. Write down the IP it prints.

Put the app on your iPhone

About 30 minutes

5

Install Xcode and XcodeGen

Xcode from the Mac App Store, then brew install xcodegen.

6

Generate the project

In the ios folder run xcodegen, then open VCXDiag.xcodeproj.

7

Sign with your Apple ID

Pick your team under Signing & Capabilities. A free Apple ID works, but the app must be reinstalled every 7 days.

8

Run it on the iPhone

Plug the iPhone in, press Run, and trust the developer under Settings › General › VPN & Device Management.

Scan a vehicle

Every time

9

Plug the VCX Nano into the OBD port

Key on, engine off. Keep it connected to the PC running the bridge.

10

Connect from the app

Same WiFi as the PC. Enter the bridge address on the Connect tab and tap Connect. Allow local network access.

11

Open the right bus

J1850 VPW (Class 2) for most GM up to 2007. HS-CAN / GMLAN for 2008 and newer.

12

Scan, read codes, watch data

Codes tab › Scan finds modules and their codes. Live data shows RPM, temps, trims and more.
